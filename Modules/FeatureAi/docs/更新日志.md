# FeatureAi 模块更新日志

## 2026-09-02 - UserAgent 支持

### 新增功能

#### 1. 全局 UserAgent 配置

支持通过配置文件设置所有 AI API 请求的 UserAgent，无需关注底层实现。

**配置方式：**

编辑 `config/ai.php`（项目根目录）：

```php
<?php

return [
    'user_agent' => 'YourApp-Name/1.0',

    // 可选：其他全局请求头
    'headers' => [
        'X-Custom-Header' => 'value',
    ],
];
```

#### 2. AiProviderService::createHttpClient()

新增工厂方法，自动注入全局配置：

```php
$httpClient = AiProviderService::createHttpClient();
```

### 修改文件

1. **Modules/FeatureAi/Services/AiProviderService.php**
   - 新增 `createHttpClient()` 静态方法

2. **Modules/FeatureAi/Services/AiChatService.php**
   - `createProvider()` 方法自动注入自定义 HttpClient
   - 所有 Provider 创建时自动携带 UserAgent

3. **Modules/FeatureAi/Services/AiImageService.php**
   - `createImageProvider()` 方法自动注入自定义 HttpClient
   - 图片生成 Provider 自动携带 UserAgent

4. **config/ai.php**（项目根目录）
   - 全局 AI 配置文件，与模块配置分离
   - 支持配置 `user_agent` 和 `headers`

### 影响范围

- ✅ 所有 Chat 服务（OpenAI、Anthropic、Gemini、Deepseek、MiniMax 等）
- ✅ 所有 Image 服务（OpenAI DALL-E、MiniMax Image-01）
- ✅ 所有通过 FeatureAi 模块发起的 AI API 请求

### 向后兼容

完全向后兼容，无需修改现有代码。如未配置 UserAgent，使用默认值 `CodeNnn-AI/1.0`。

### 使用示例

无需修改任何调用代码，配置后自动生效：

```php
// 现有代码保持不变
$response = AiChatService::generateText('你好');

// 所有请求自动携带 UserAgent: YourApp-Name/1.0
```

### 配置说明

- **配置位置**：`config/ai.php`（项目根目录）
- **与模块配置分离**：模块内部配置在 `Modules/FeatureAi/config/`，不影响全局配置
- **修改生效**：修改配置后立即生效，无需重启服务
