# NeuronAI Agent 交互快速参考

## 三种交互方式对比

| 方式 | 触发者 | 触发时机 | 典型场景 | 复杂度 |
|------|--------|---------|---------|--------|
| **ToolApproval** | 系统（自动） | 工具执行前 | 敏感操作确认 | ⭐ |
| **AskTool** | Agent（主动） | Agent 需要信息时 | 信息收集 | ⭐⭐ |
| **Workflow Interrupt** | 开发者（手动） | 任意节点 | 复杂流程 | ⭐⭐⭐ |

---

## 方式一：ToolApproval（工具确认）

### 使用步骤

```php
// 1. 注册中间件
protected function middleware(): array
{
    return [
        new ToolApproval(['delete_file']), // 指定工具需确认
    ];
}

// 2. 捕获中断
try {
    $response = $agent->chat('删除文件');
} catch (WorkflowInterrupt $interrupt) {
    $request = $interrupt->getRequest();

    // 3. 用户决策
    foreach ($request->getActions() as $action) {
        $action->approve();  // 或 reject()
    }

    // 4. 恢复执行
    $response = $agent->chat('继续', $request);
}
```

### 核心类

```php
ApprovalRequest {
    public string $message;
    public array $actions;
    public function getAction($id): ?Action;
}

Action {
    public string $id, $name, $description;
    public function approve(?string $feedback = null): void;
    public function reject(?string $feedback = null): void;
}
```

## 方式二：AskTool（主动提问）

### 使用步骤

```php
// 1. 注册工具
protected function tools(): array
{
    return [new AskTool()];
}

// 2. 捕获异常
try {
    $response = $agent->chat('帮我注册');
} catch (AskRequiredException $e) {
    // 3. 展示问题
    echo $e->getQuestion();

    // 4. 提交答案
    AskTool::answer($e->getQuestionId(), '用户答案');

    // 5. 继续执行
    $response = $agent->chat('继续');
}
```

### 核心类

```php
AskTool {
    public static function answer(string $id, string $answer): void;
    public static function getAnswer(string $id): ?string;
}

AskRequiredException {
    public string $question, $questionId, $context, $default;
    public function getQuestion(): string;
    public function getQuestionId(): string;
}
```

## 方式三：Workflow Interrupt（自定义中断）

### 使用步骤

```php
// 1. 在节点中中断
class MyNode extends Node
{
    public function __invoke($event, $state)
    {
        if ($this->isResuming()) {
            // 恢复时获取用户输入
            $input = $this->getResumeRequest();
            return new ResultEvent($input);
        }

        // 首次执行，请求用户输入
        $this->interrupt(new ApprovalRequest(
            '需要用户确认',
            [new Action('yes', '确认', '')]
        ));
    }
}

// 2. 外部处理
try {
    $workflow->init()->run();
} catch (WorkflowInterrupt $interrupt) {
    $request = $interrupt->getRequest();
    // ... 用户操作
    $workflow->init($request)->run(); // 恢复
}
```

## 快速选择指南

### 需要工具确认？
```
YES → ToolApproval
NO  → 是否需要主动收集信息？
      YES → AskTool
      NO  → 是否需要复杂交互流程？
            YES → Workflow Interrupt
            NO  → 不需要交互
```

### 典型场景映射

| 场景 | 推荐方式 |
|------|---------|
| 删除文件前确认 | ToolApproval |
| 大额支付确认 | ToolApproval |
| 用户注册收集信息 | AskTool |
| 表单填写引导 | AskTool |
| 多级审批流程 | Workflow Interrupt |
| 条件分支交互 | Workflow Interrupt |

## 代码模板

### ToolApproval 模板

```php
use NeuronAI\Agent\Middleware\ToolApproval;

class SafeAgent extends Agent
{
    protected function middleware(): array
    {
        return [
            new ToolApproval(['敏感工具名称']),
        ];
    }
}
```

### AskTool 模板

```php
use Modules\FeatureAi\Tools\AskTool;

class DataCollectionAgent extends Agent
{
    protected function tools(): array
    {
        return [new AskTool()];
    }

    public function instructions(): string
    {
        return '需要用户信息时使用 ask 工具提问';
    }
}
```

### Workflow Interrupt 模板

```php
use NeuronAI\Workflow\Node;
use NeuronAI\Workflow\Interrupt\ApprovalRequest;
use NeuronAI\Workflow\Interrupt\Action;

class InteractiveNode extends Node
{
    public function __invoke($event, $state)
    {
        if ($this->isResuming()) {
            return $this->processUserInput();
        }

        $this->interrupt(new ApprovalRequest(
            message: '需要用户决策',
            actions: [new Action('id', '名称', '描述')]
        ));
    }
}
```

## 异常处理模板

```php
try {
    $response = $agent->chat($message);
    return $response->getContent();
} catch (AskRequiredException $e) {
    // AskTool 提问
    return $this->handleAsk($e);
} catch (WorkflowInterrupt $interrupt) {
    // ToolApproval 或其他中断
    return $this->handleInterrupt($interrupt);
} catch (Exception $e) {
    // 其他异常
    Log::error('Agent error', ['error' => $e->getMessage()]);
    throw $e;
}
```

## 常用方法速查

### ApprovalRequest

```php
$request->getActions();           // 获取所有操作
$request->getAction($id);         // 获取指定操作
$request->getApprovedActions();   // 获取已批准操作
$request->getRejectedActions();   // 获取已拒绝操作
```

### Action

```php
$action->approve($feedback);      // 批准
$action->reject($feedback);       // 拒绝
$action->edit($inputs, $feedback);// 编辑参数

$action->isPending();             // 是否待处理
$action->isApproved();            // 是否已批准
$action->isRejected();            // 是否已拒绝
```

### AskTool

```php
AskTool::answer($id, $answer);    // 提交答案
AskTool::getAnswer($id);          // 获取答案
AskTool::getQuestion($id);        // 获取问题
```

### WorkflowInterrupt

```php
$interrupt->getRequest();         // 获取中断请求
$interrupt->getWorkflowId();      // 获取 Workflow ID
```
