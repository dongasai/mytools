## 一、模块简介

### 1.1 功能定位

Notification 模块提供统一的通知发送和管理系统，支持多种通知渠道（database/mail/sms/push）。

**核心功能**：
- 通知模板管理（动态配置通知内容）
- 通知发送队列（异步处理，失败重试）
- 通知日志记录（完整发送历史）
- DcatAdmin 后台管理（通知日志、模板管理）
- 多渠道支持（database 渠道已实现）

### 1.2 技术栈

- **PHP**: 8.3 | **Laravel**: 12
- **队列系统**: Laravel Queue (database驱动)
- **后台管理**: Dcat Admin 2.x
- **通知组件**: Laravel Notifications
- **分层架构**: Models → Logic → Service → Controllers

## 二、架构设计

### 2.1 分层架构

```
Models（数据层）
    ↓ NotificationLog、NotificationTemplate
Logic（逻辑层）
    ↓ NotificationLogic、TemplateLogic（静态方法）
Service（服务层）
    ↓ ModuleNotificationService、NotificationService、HookManager
Queue（队列层）
    ↓ SendNotificationQueue
Notifications（通知类层）
    ↓ BaseNotification、WelcomeNotification
DcatAdmin Controllers（后台层）
    ↓ NotificationLogController、NotificationTemplateController
```

### 2.2 数据流

```
业务模块调用
    ↓
ModuleNotificationService::send()
    ↓
TemplateLogic::renderTemplate() → 模板渲染
    ↓
NotificationLogic::createLog() → 创建日志
    ↓
SendNotificationQueue::dispatch() → 推送队列
    ↓
NotificationService::handleNotification() → 队列执行
    ↓
NotificationService::sendToDatabase() → 渠道发送
    ↓
NotificationLogic::markAsSent() → 状态更新
```

## 三、核心组件

### 3.1 数据模型

**NotificationLog**（通知日志）：
- 记录所有通知发送历史
- 多态关联接收对象（notifiable_type/notifiable_id）
- 状态管理（pending/sending/sent/failed）
- 支持重试机制（retry_count）

**NotificationTemplate**（通知模板）：
- 动态配置通知内容
- 支持多渠道模板
- 变量替换机制（`{变量名}` 格式）
- 启用状态控制

### 3.2 Logic 层

**NotificationLogic**：
- 创建通知日志（单个、批量）
- 状态更新方法（markAsSending、markAsSent、markAsFailed）
- 重试管理（incrementRetry）
- 统计查询（getStatusStatistics）

**TemplateLogic**：
- 查找激活模板（findActiveTemplate）
- 模板渲染（renderTemplateContent、renderTemplateSubject）
- 变量验证（validateVariables）

### 3.3 Service 层

**ModuleNotificationService**：
- 模块对外接口（供其他模块调用）
- 全静态方法设计
- 发送通知（单个、批量）
- 获取统计信息

**NotificationService**：
- 处理队列任务执行
- 渠道发送逻辑（sendByChannel）
- database 渠道实现（sendToDatabase）
- 钩子管理（HookManager）

**HookManager**：
- 钩子注册机制
- 发送前/后钩子执行
- 错误处理钩子

### 3.4 队列系统

**SendNotificationQueue**：
- 继承 QueueJob 基类
- 异步处理通知发送
- 支持失败重试（tries=3）
- 超时控制（timeout=60秒）

### 3.5 通知类

**BaseNotification**（抽象基类）：
- 继承 Laravel Notification
- 定义通知类型标识
- 提供默认内容方法
- 模板渲染集成

**WelcomeNotification**（示例）：
- 欢迎通知示例类
- 支持 database 渠道
- 演示模板覆盖机制

## 四、渠道实现状态

### 4.1 Database 渠道

**状态**：✅ 已完整实现

**功能**：
- 存储通知到 Laravel notifications 表
- 使用 `$notifiable->notifications()->create()`
- 记录通知类型、数据、接收对象

**发送逻辑**：
```php
NotificationService::sendToDatabase(array $data): bool
{
    $notifiable->notifications()->create([
        'id' => uuid_create(UUID_TYPE_RANDOM),
        'type' => $data['notification_type'],
        'notifiable_id' => $notifiable->id,
        'notifiable_type' => get_class($notifiable),
        'data' => json_encode($data['data']),
        'read_at' => null,
    ]);
    return true;
}
```

## 七、使用示例

### 7.1 发送通知

```php
use Modules\Notification\Services\ModuleNotificationService;

// 单个发送
$log = ModuleNotificationService::send(
    'WelcomeNotification',
    'database',
    $user,
    ['username' => '张三', 'timestamp' => now()]
);

// 批量发送
$logs = ModuleNotificationService::sendBatch(
    'WelcomeNotification',
    'database',
    [$user1, $user2, $user3],
    ['username' => '批量用户', 'timestamp' => now()]
);

// 获取统计
$stats = ModuleNotificationService::getStatistics();
```

### 7.2 创建模板

**后台操作**：
1. 访问 `/admin/module_notification/notification-templates`
2. 点击"新建"
3. 填写配置：
   - 名称：欢迎通知模板
   - 类型：WelcomeNotification
   - 渠道：database
   - 内容：欢迎 {username} 加入平台！
   - 变量：username
   - 启用：true
4. 提交保存

**测试验证**：
```bash
php artisan notification:template
```
