## 三、详细实现情况

### 3.1 模板基类（核心架构）

**设计要求**: `Templates/Base/AbstractImportTemplate.php`

**当前实现**: ❌ 不存在

**问题**:
- 当前 `Engines/Template/ImportTemplate.php` 是**数据对象**（只有 setter/getter）
- 缺少抽象方法 `defineFields()`
- 缺少钩子方法 `validateRow()` / `transformRow()`
- 业务模块无法继承实现

**重构需求**:
```
需要创建：
Templates/Base/AbstractImportTemplate.php  (抽象基类)
Templates/Base/AbstractExportTemplate.php  (抽象基类)

废弃删除：
Engines/Template/ImportTemplate.php  (数据对象，改名为基类)

```

## 四、架构问题总结

### 核心问题：v2.0 配置文件模式

**当前错误架构**:
```
业务模块定义配置文件
├── config/import_templates.php
└── config/export_templates.php
      ↓
TemplateParser::parseImportTemplate(array $config)
      ↓
ImportTemplate/ExportTemplate（数据对象）
      ↓
ImportService/ExportService
```

**设计正确架构**:
```
业务模块定义模板类
├── ImportTemplates/EnergyDataImportTemplate
└── 继承 AbstractImportTemplate
      ↓
实现 defineFields() 方法
      ↓
ModuleFeatureExcelService（统一服务）
```
