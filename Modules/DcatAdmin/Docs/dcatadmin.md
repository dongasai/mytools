# dcat admin 笔记本

 admin:action                             Make a admin action
  admin:app                                Create new application
  admin:check-menu-validity                检查菜单项是否有效，包括检查是否有对应的控制器和路由
  admin:check-specific-menus               检查特定ID的菜单项是否指向有效的控制器，并可选择删除无效的菜单项
  admin:create-user                        Create a admin user
  admin:dev                                
  admin:export-seed                        Export seed a dcat-admin database tables menu, roles and permissions
  admin:ext-disable                        Disable an existing extension
  admin:ext-enable                         Enable an existing extension
  admin:ext-install                        Install an extension
  admin:ext-make                           Build a dcat-admin extension
  admin:ext-refresh                        Removes and re-adds an existing extension
  admin:ext-rollback                       Rollback an existing extension
  admin:ext-uninstall                      Uninstall an existing extension
  admin:ext-update                         Update an existing extension
  admin:form                               Make admin form widget
  admin:ide-helper                         Create the ide-helper file
  admin:install                            Install the admin package
  admin:menu-cache                         Flush the menu cache
  admin:minify                             Minify the CSS and JS
  admin:publish                            Re-publish dcat-admin's assets, configuration, language and migration files. If you want overwrite the existing files, you can add the `--force` option
  admin:reset-password                     Reset password for a specific admin user
  admin:uninstall                          Uninstall the admin package
  admin:update                             Update the admin package
