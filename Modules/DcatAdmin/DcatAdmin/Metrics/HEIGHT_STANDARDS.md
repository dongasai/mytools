# Metrics 高度规范

## 核心理解

**`height()` 方法设置的是整个卡片的 BOX 高度（总高度），而不是内容高度！**

```
总高度 = 标题栏（~45px）+ 内容区域
```

## 嵌套卡片高度计算

### NumberS 嵌套规则

当卡片嵌套多个子卡片时，需要计算总高度：

**公式**: `子卡片高度 * n + 85`（n = 嵌套数量）

**示例**（每个 Number = 150px）：
- **1 个 Number**: 150px（标准）
- **2 个 Number**: `150 * 2 + 85 = 385px ≈ 400px`
- **3 个 Number**: `150 * 3 + 85 = 535px ≈ 550px`
- **4 个 Number**: `150 * 4 + 85 = 685px ≈ 700px`

**说明**:
- 基础高度 = 所有子卡片高度之和
- 额外 85px = 标题栏（45px）+ 内边距（40px）

## 高度标准（五级体系）

| 级别 | 倍数 | 卡片总高度 | 内容区域 | 适用场景 | 示例 |
|------|------|----------|---------|----------|------|
| **小型** | 1.5x | **150px** | ~105px | 简单数字展示 | 企业总数、用户总数、能源品种、能耗、碳排、产品数 |
| **中型** | 2x | **200px** | ~155px | 列表展示（3-4项）| 待定 |
| **大型** | 3x | **300px** | ~255px | 检查展示、图表 | 文件存储检查、数据库自查、企业趋势 |
| **超大型** | 4x | **400px** | ~355px | 复杂内容、大数据表 | 待定 |
| **超大复杂型** | 5x | **500px** | ~455px | 环形图+多统计、复杂组合 | Tickets（环形图+4个数字统计）|
| **嵌套型** | 动态 | **计算** | 动态 | 嵌套子卡片 | NumberS（2个Number嵌套=400px）|

## 高度计算

```php
// 小型卡片（总高度 150px）
$this->height(150);  // 标题栏 45px + 内容区域 105px

// 中型卡片（总高度 200px）
$this->height(200);  // 标题栏 45px + 内容区域 155px

// 大型卡片（总高度 300px）
$this->height(300);  // 标题栏 45px + 内容区域 255px

// 超大型卡片（总高度 400px）
$this->height(400);  // 标题栏 45px + 内容区域 355px
```

## 使用场景

### 1.5x (150px 总高度) - 小型卡片
- EnterpriseTotalMetric

- ProductionProductCountMetric

### 2x (200px 总高度) - 中型卡片
- 待定（适合 3-4 个列表项的卡片）

### 3x (300px 总高度) - 大型卡片
- FileStorageConfigCheckMetric

### 4x (400px 总高度) - 超大型卡片

- Tickets（环形图+4个数字统计）

## 内容区域规划

### 小型卡片（~105px）
- **两行布局**：图标 + 数字+单位
- **紧凑样式**：`padding: 0.5rem`, `line-height: 1.3`
- **图标大小**：`fa-lg` 或 `font-size: 1.75rem`

### 中型卡片（~155px）
- **三行布局**：标题 + 3个列表项
- **适中样式**：`padding: 0.75rem`, `line-height: 1.4`
- **列表项**：`py-1 px-2`

### 大型卡片（~255px）
- **四行布局**：标题 + 4-5个列表项
- **舒适样式**：`padding: 1rem`, `line-height: 1.5`
- **列表项**：`py-2 px-3`

### 超大型卡片（~355px）
- **复杂布局**：大数据表、多个区块
- **宽松样式**：`padding: 1.5rem`, `line-height: 1.6`

### 超大复杂型卡片（~455px）
- **极复杂布局**：环形图+多统计、复杂组合
- **舒适样式**：`padding: 1.5rem`, `line-height: 1.6`

## 注意事项

1. **内容区域有限**：小型卡片只有 ~105px 的内容空间，设计样式时需考虑紧凑性
2. **图标大小**：小型用 `fa-lg`，中型用 `fa-2x`，大型以上可用 `fa-2x`
3. **行间距**：小型用 `line-height: 1.2-1.3`，大型可用 `1.4-1.6`
4. **避免 h1-h3**：使用 `div` + `font-size` 控制数字大小，避免标题标签的默认间距
5. **根据内容选择级别**：
   - 2 行内容 → 150px
   - 3-4 行列表 → 200px
   - 4-6 行列表/图表 → 300px
   - 复杂内容/大数据表 → 400px
   - 环形图+多统计 → 500px
6. **坚持标准级别**：始终使用标准高度（150/200/300/400/500），不随意添加中间值

## 升级指南

### 从 150px 升级到 200px
- 内容超过 105px
- 需要 3-4 个列表项
- 图标可以使用 `fa-2x`

### 从 200px 升级到 300px
- 内容超过 155px
- 需要 4-6 个列表项
- 包含图表
- 需要检查类展示

### 从 300px 升级到 400px
- 内容超过 255px
- 包含大数据表
- 多个区块组合
- 复杂交互元素

### 从 400px 升级到 500px
- 内容超过 355px
- 环形图+多个统计数字
- 极复杂组合内容
