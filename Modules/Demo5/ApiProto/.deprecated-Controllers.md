# ApiProto/Controllers 目录已废弃

## 废弃原因

统一入口架构改造，Handler 替代 Controller。

## 原架构（已废弃）

```
Modules/Demo5/ApiProto/Controllers/
├── PostProtoController.php  ← 已删除
```

路由文件：`Modules/Demo5/routes/api_proto.php` ← 已删除
ServiceProvider：`RouteApiProtoServiceProvider.php` ← 已删除

## 新架构（Handler架构）

```
Modules/Demo5/ApiProto/Handlers/
├── PostGetHandler.php      ← 处理文章详情
├── PostListHandler.php     ← 处理文章列表
├── PostCreateHandler.php   ← 处理创建文章
```

统一入口：`Modules/ApiProto/Controllers/UnifiedProtobufController.php`
路由格式：`/api/proto/demo5/post/{action}`

## Handler vs Controller

| Controller | Handler |
|------------|---------|
| 继承 BaseProtoController | 继承 BaseHandler |
| 多个方法（index/show/store/update/destroy） | 单一 handle() 方法 |
| HTTP Request → DTO → Message | 直接处理 Proto Message |
| 返回 JsonResponse | 返回 Proto Message |
| 显性路由配置 | 命名约定自动定位 |
