# FeatureDbadmin 模块

## 模块定位

**数据库管理员模块** - 提供数据库/模式/表的 CRUD 操作和可视化管理工具

## 核心功能

### 数据库管理
- 数据库连接管理
- 数据库创建/删除
- 数据库信息查看

### 模式管理
- Schema 创建/删除
- Schema 权限管理
- Schema 信息查看

### 表管理
- 表结构查看
- 表结构导出（SQL/Markdown/JSON）
- 表创建/修改/删除
- 表字段管理
- 表索引管理

### 数据管理
- 数据浏览（分页、搜索、排序）
- 数据编辑（新增/修改/删除）
- 数据导出（CSV/Excel/JSON）
- 数据导入

### SQL 工具
- SQL 查询执行
- 查询历史记录
- SQL 格式化
- 查询结果导出

## 数据表前缀

`feature_dbadmin_`

## 模块特性

- ✅ 数据库连接管理
- ✅ 表结构可视化
- ✅ SQL 查询工具
- ✅ 数据 CRUD 操作
- ✅ 结构导出功能

## 技术架构

### 分层架构
```
Models → Services → Logics → Controllers(DcatAdmin)
```

### 核心组件
- **Models**: 数据库连接配置、查询历史记录
- **Services**: 数据库操作服务、表结构分析服务
- **Logics**: 数据转换逻辑、SQL 解析逻辑
- **Controllers**: Dcat Admin 后台管理界面

## 模块依赖

- **ABase**: 基础设施（ServiceProvider基类、Hook、Event）

## 使用场景

### 超管后台
- 路径: `/admin/dbadmin`
- 功能: 系统数据库可视化管理
- 用户: 超级管理员

## 安全特性

- 仅限超级管理员访问
- SQL 执行权限控制
- 敏感数据脱敏
- 操作审计日志
