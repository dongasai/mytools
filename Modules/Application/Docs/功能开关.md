# 功能开关技术方案

## 功能概述

### 原始需求

功能开关系统支持以下核心能力：

1. **用户级别开启/关闭**：支持对单个用户精确控制功能的启用状态
2. **白名单机制**：指定特定用户可以开启某功能（即使全局关闭）
3. **黑名单机制**：指定特定用户强制关闭某功能（即使全局开启）
4. **功能表管理**：集中管理所有功能开关的定义和配置

### 业务价值

功能开关系统在实际业务中的应用场景：

- **灰度发布**：新功能先对小范围用户开放，验证后全量开放
- **风险控制**：发现功能异常时，快速关闭特定用户的功能访问
- **VIP特权**：付费用户专属功能，通过白名单机制实现
- **测试验证**：内部测试用户通过白名单提前体验新功能
- **故障隔离**：异常用户通过黑名单暂时禁用功能

### 判断优先级

功能开关的判断遵循以下优先级规则：

```
黑名单 > 白名单 > 用户个人设置 > 功能默认状态
```

**优先级说明**：

1. **最高优先级 - 黑名单**：如果用户在黑名单中，强制关闭该功能，无法被其他规则覆盖
2. **第二优先级 - 白名单**：如果用户在白名单中，强制开启该功能（前提：不在黑名单中）
3. **第三优先级 - 用户个人设置**：用户自己配置的开关状态（前提：不在黑白名单中）
4. **最低优先级 - 功能默认状态**：功能的默认开启/关闭状态

## 数据库设计

### 表结构设计

采用**四表设计**，清晰分离功能定义、用户设置、白名单和黑名单。

#### 1. features 表（功能定义表）

存储所有功能开关的定义信息。

```sql
CREATE TABLE `features` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT COMMENT '功能ID',
  `name` varchar(100) NOT NULL COMMENT '功能名称',
  `key` varchar(100) NOT NULL COMMENT '功能标识（唯一）',
  `description` text COMMENT '功能描述',
  `is_enabled` tinyint(1) NOT NULL DEFAULT '0' COMMENT '默认状态：0关闭 1开启',
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_key` (`key`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='功能定义表';
```

**字段说明**：
- `key`：功能唯一标识，用于代码中引用（如 `ai_write`、`vip_theme`）
- `is_enabled`：功能默认状态，新用户未配置时使用此值

---

#### 2. user_feature_settings 表（用户个人开关表）

存储用户对功能的个性化配置。

```sql
CREATE TABLE `user_feature_settings` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `user_id` bigint unsigned NOT NULL COMMENT '用户ID',
  `feature_id` bigint unsigned NOT NULL COMMENT '功能ID',
  `is_enabled` tinyint(1) NOT NULL DEFAULT '0' COMMENT '开关状态：0关闭 1开启',
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_feature` (`user_id`, `feature_id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_feature_id` (`feature_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户功能开关配置表';
```

**字段说明**：
- `user_id + feature_id`：唯一键，确保一个用户对一个功能只有一条配置
- `is_enabled`：用户个人设置的开关状态

---

#### 3. feature_whitelist 表（白名单表）

存储指定用户可以开启的功能白名单。

```sql
CREATE TABLE `feature_whitelist` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `feature_id` bigint unsigned NOT NULL COMMENT '功能ID',
  `user_id` bigint unsigned NOT NULL COMMENT '用户ID',
  `reason` varchar(255) DEFAULT NULL COMMENT '加入白名单原因',
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_feature_user` (`feature_id`, `user_id`),
  KEY `idx_feature_id` (`feature_id`),
  KEY `idx_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='功能白名单表';
```

**字段说明**：
- `reason`：记录加入白名单的原因，便于管理和审计

---

#### 4. feature_blacklist 表（黑名单表）

存储指定用户强制关闭的功能黑名单。

```sql
CREATE TABLE `feature_blacklist` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `feature_id` bigint unsigned NOT NULL COMMENT '功能ID',
  `user_id` bigint unsigned NOT NULL COMMENT '用户ID',
  `reason` varchar(255) DEFAULT NULL COMMENT '加入黑名单原因',
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_feature_user` (`feature_id`, `user_id`),
  KEY `idx_feature_id` (`feature_id`),
  KEY `idx_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='功能黑名单表';
```

**字段说明**：
- `reason`：记录加入黑名单的原因，便于管理决策和后续解除

```php
<?php

namespace Modules\Application\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\HasMany;

/**
 * 功能定义模型
 */
class Feature extends Model
{
    protected $table = 'features';

    protected $fillable = [
        'name',
        'key',
        'description',
        'is_enabled',
    ];

    protected $casts = [
        'is_enabled' => 'boolean',
    ];

    /**
     * 用户个人设置关联
     */
    public function userSettings(): HasMany
    {
        return $this->hasMany(UserFeatureSetting::class, 'feature_id');
    }

    /**
     * 白名单关联
     */
    public function whitelist(): HasMany
    {
        return $this->hasMany(FeatureWhitelist::class, 'feature_id');
    }

    /**
     * 黑名单关联
     */
    public function blacklist(): HasMany
    {
        return $this->hasMany(FeatureBlacklist::class, 'feature_id');
    }
}
```

### Services 层（Modules/Application/Services/FeatureService.php）

**职责**：协调组件、处理复杂业务逻辑，**禁止读取 HTTP/session**，参数由 Controller 显性传入。

```php
<?php

namespace Modules\Application\Services;

use Modules\Application\Models\Feature;
use Modules\Application\Models\UserFeatureSetting;
use Modules\Application\Models\FeatureWhitelist;
use Modules\Application\Models\FeatureBlacklist;
use Illuminate\Support\Collection;

/**
 * 功能开关服务
 *
 * 负责功能开关的判断、配置和管理
 */
class FeatureService
{
    /**
     * 判断用户是否拥有某个功能
     *
     * @param int $userId 用户ID
     * @param string $featureKey 功能标识
     * @return bool
     */
    public static function isEnabled(int $userId, string $featureKey): bool
    {
        // 获取功能定义
        $feature = Feature::where('key', $featureKey)->first();
        if (!$feature) {
            return false; // 功能不存在，默认关闭
        }

        // 优先级1：检查黑名单
        if (FeatureBlacklist::where('feature_id', $feature->id)
            ->where('user_id', $userId)
            ->exists()) {
            return false; // 黑名单强制关闭
        }

        // 优先级2：检查白名单
        if (FeatureWhitelist::where('feature_id', $feature->id)
            ->where('user_id', $userId)
            ->exists()) {
            return true; // 白名单强制开启
        }

        // 优先级3：检查用户个人设置
        $userSetting = UserFeatureSetting::where('user_id', $userId)
            ->where('feature_id', $feature->id)
            ->first();
        if ($userSetting) {
            return $userSetting->is_enabled;
        }

        // 优先级4：返回功能默认状态
        return $feature->is_enabled;
    }

    /**
     * 获取用户所有可用功能列表
     *
     * @param int $userId 用户ID
     * @return Collection
     */
    public static function getUserEnabledFeatures(int $userId): Collection
    {
        $allFeatures = Feature::all();

        return $allFeatures->filter(function ($feature) use ($userId) {
            return self::isEnabled($userId, $feature->key);
        });
    }

    /**
     * 设置用户个人功能开关
     *
     * @param int $userId 用户ID
     * @param string $featureKey 功能标识
     * @param bool $enabled 开关状态
     * @return UserFeatureSetting
     */
    public static function setUserFeatureSetting(
        int $userId,
        string $featureKey,
        bool $enabled
    ): UserFeatureSetting {
        $feature = Feature::where('key', $featureKey)->firstOrFail();

        return UserFeatureSetting::updateOrCreate(
            [
                'user_id' => $userId,
                'feature_id' => $feature->id,
            ],
            [
                'is_enabled' => $enabled,
            ]
        );
    }

    /**
     * 添加用户到白名单
     *
     * @param int $userId 用户ID
     * @param string $featureKey 功能标识
     * @param string|null $reason 原因
     * @return FeatureWhitelist
     */
    public static function addToWhitelist(
        int $userId,
        string $featureKey,
        ?string $reason = null
    ): FeatureWhitelist {
        $feature = Feature::where('key', $featureKey)->firstOrFail();

        return FeatureWhitelist::updateOrCreate(
            [
                'feature_id' => $feature->id,
                'user_id' => $userId,
            ],
            [
                'reason' => $reason,
            ]
        );
    }

    /**
     * 添加用户到黑名单
     *
     * @param int $userId 用户ID
     * @param string $featureKey 功能标识
     * @param string|null $reason 原因
     * @return FeatureBlacklist
     */
    public static function addToBlacklist(
        int $userId,
        string $featureKey,
        ?string $reason = null
    ): FeatureBlacklist {
        $feature = Feature::where('key', $featureKey)->firstOrFail();

        return FeatureBlacklist::updateOrCreate(
            [
                'feature_id' => $feature->id,
                'user_id' => $userId,
            ],
            [
                'reason' => $reason,
            ]
        );
    }

    /**
     * 从白名单移除用户
     *
     * @param int $userId 用户ID
     * @param string $featureKey 功能标识
     * @return bool
     */
    public static function removeFromWhitelist(int $userId, string $featureKey): bool
    {
        $feature = Feature::where('key', $featureKey)->firstOrFail();

        return FeatureWhitelist::where('feature_id', $feature->id)
            ->where('user_id', $userId)
            ->delete() > 0;
    }

    /**
     * 从黑名单移除用户
     *
     * @param int $userId 用户ID
     * @param string $featureKey 功能标识
     * @return bool
     */
    public static function removeFromBlacklist(int $userId, string $featureKey): bool
    {
        $feature = Feature::where('key', $featureKey)->firstOrFail();

        return FeatureBlacklist::where('feature_id', $feature->id)
            ->where('user_id', $userId)
            ->delete() > 0;
    }
}
```

### Logics 层（Modules/Application/Logics/FeatureLogic.php）

**职责**：数据组装/单一逻辑，**静态方法**，无状态，高性能。

```php
<?php

namespace Modules\Application\Logics;

use Modules\Application\Services\FeatureService;
use Illuminate\Support\Collection;

/**
 * 功能开关逻辑层
 *
 * 提供静态方法，无状态，高性能
 */
class FeatureLogic
{
    /**
     * 快速判断功能是否开启
     *
     * @param int $userId 用户ID
     * @param string $featureKey 功能标识
     * @return bool
     */
    public static function check(int $userId, string $featureKey): bool
    {
        return FeatureService::isEnabled($userId, $featureKey);
    }

    /**
     * 获取用户可用功能键列表
     *
     * @param int $userId 用户ID
     * @return array
     */
    public static function getEnabledFeatureKeys(int $userId): array
    {
        $features = FeatureService::getUserEnabledFeatures($userId);

        return $features->pluck('key')->toArray();
    }

    /**
     * 批量判断多个功能开关
     *
     * @param int $userId 用户ID
     * @param array $featureKeys 功能标识数组
     * @return array ['feature_key' => bool]
     */
    public static function batchCheck(int $userId, array $featureKeys): array
    {
        $result = [];
        foreach ($featureKeys as $key) {
            $result[$key] = FeatureService::isEnabled($userId, $key);
        }

        return $result;
    }
}
```

### Controllers 层

#### Api Controller（Modules/Application/Api/Controllers/FeatureController.php）

提供客户端 API 接口。

```php
<?php

namespace Modules\Application\Api\Controllers;

use Modules\Application\Logics\FeatureLogic;
use Modules\Application\Services\FeatureService;
use Illuminate\Http\Request;
use Illuminate\Http\JsonResponse;

/**
 * 功能开关 API 控制器
 */
class FeatureController
{
    /**
     * 获取用户可用功能列表
     *
     * @param Request $request
     * @return JsonResponse
     */
    public function list(Request $request): JsonResponse
    {
        $userId = $request->user()->id;

        $featureKeys = FeatureLogic::getEnabledFeatureKeys($userId);

        return response()->json([
            'features' => $featureKeys,
        ]);
    }

    /**
     * 检查单个功能是否开启
     *
     * @param Request $request
     * @param string $featureKey 功能标识
     * @return JsonResponse
     */
    public function check(Request $request, string $featureKey): JsonResponse
    {
        $userId = $request->user()->id;

        $enabled = FeatureLogic::check($userId, $featureKey);

        return response()->json([
            'feature_key' => $featureKey,
            'enabled' => $enabled,
        ]);
    }

    /**
     * 批量检查功能开关
     *
     * @param Request $request
     * @return JsonResponse
     */
    public function batchCheck(Request $request): JsonResponse
    {
        $userId = $request->user()->id;
        $featureKeys = $request->input('feature_keys', []);

        $result = FeatureLogic::batchCheck($userId, $featureKeys);

        return response()->json([
            'features' => $result,
        ]);
    }

    /**
     * 设置用户个人功能开关
     *
     * @param Request $request
     * @return JsonResponse
     */
    public function setSetting(Request $request): JsonResponse
    {
        $userId = $request->user()->id;
        $featureKey = $request->input('feature_key');
        $enabled = $request->input('enabled', false);

        FeatureService::setUserFeatureSetting($userId, $featureKey, $enabled);

        return response()->json([
            'message' => '设置成功',
        ]);
    }
}
```

## 判断逻辑流程

### 判断流程图（文字描述）

```
开始判断：用户是否有功能 X？

步骤1：检查黑名单
→ 查询 feature_blacklist 表
→ 如果 user_id 在 feature_id 的黑名单中：
    → 返回 false（强制关闭）
→ 否则：继续

步骤2：检查白名单
→ 查询 feature_whitelist 表
→ 如果 user_id 在 feature_id 的白名单中：
    → 返回 true（强制开启）
→ 否则：继续

步骤3：检查用户个人设置
→ 查询 user_feature_settings 表
→ 如果存在 user_id + feature_id 的配置：
    → 返回 is_enabled 值（用户个人选择）
→ 否则：继续

步骤4：返回功能默认状态
→ 查询 features 表
→ 返回 feature.is_enabled（功能默认开关）

结束
```

### 判断伪代码

```php
function checkFeature(userId, featureKey) {
    // 1. 获取功能定义
    feature = getFeatureByKey(featureKey)
    if (!feature) return false

    // 2. 黑名单检查（最高优先级）
    if (isInBlacklist(userId, feature.id)) {
        return false // 强制关闭，不可覆盖
    }

    // 3. 白名单检查（第二优先级）
    if (isInWhitelist(userId, feature.id)) {
        return true // 强制开启
    }

    // 4. 用户个人设置检查（第三优先级）
    userSetting = getUserSetting(userId, feature.id)
    if (userSetting) {
        return userSetting.is_enabled
    }

    // 5. 功能默认状态（最低优先级）
    return feature.is_enabled
}
```

---

### 优先级规则总结

| 优先级 | 规则 | 强制性 | 说明 |
|--------|------|--------|------|
| 1 | 黑名单 | 强制关闭 | 用户在黑名单中，功能必须关闭 |
| 2 | 白名单 | 强制开启 | 用户在白名单中（且不在黑名单），功能必须开启 |
| 3 | 用户个人设置 | 可覆盖 | 用户自己配置的开关，可被黑白名单覆盖 |
| 4 | 功能默认状态 | 默认值 | 新用户未配置时使用的默认状态 |

**关键点**：
- 黑名单和白名单是管理员控制的强制规则，用户无法修改
- 用户个人设置只在黑白名单都不存在时生效
- 黑名单优先级高于白名单，确保安全控制

## API 接口设计

### 接口列表

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 获取可用功能列表 | GET | `/api/features` | 返回用户当前可用的所有功能 |
| 检查单个功能 | GET | `/api/features/{key}/check` | 检查某个功能是否对用户开启 |
| 批量检查功能 | POST | `/api/features/batch-check` | 批量检查多个功能开关状态 |
| 设置个人开关 | POST | `/api/features/settings` | 用户设置自己的功能开关 |

---

### 接口详细设计

#### 1. 获取可用功能列表

**请求**：
```http
GET /api/features
Authorization: Bearer {token}
```

**响应**：
```json
{
  "features": [
    "ai_write",
    "vip_theme",
    "dark_mode"
  ]
}
```

**说明**：返回用户当前可用的功能 `key` 列表。

---

#### 2. 检查单个功能

**请求**：
```http
GET /api/features/{key}/check
Authorization: Bearer {token}
```

**响应**：
```json
{
  "feature_key": "ai_write",
  "enabled": true
}
```

**说明**：返回单个功能的开启状态。

---

#### 3. 批量检查功能

**请求**：
```http
POST /api/features/batch-check
Authorization: Bearer {token}
Content-Type: application/json

{
  "feature_keys": ["ai_write", "vip_theme", "dark_mode"]
}
```

## 性能优化建议

### 何时需要缓存

当用户量达到以下阈值时，建议引入 Redis 缓存层：

- **用户量 < 1万**：无需缓存，数据库查询足够
- **用户量 1-10万**：建议缓存热点功能（高频访问的功能）
- **用户量 > 10万**：必须引入缓存，否则性能下降明显

---

### Redis 缓存方案

#### 缓存 Key 设计

```
user:{user_id}:feature:{feature_key} = "true/false"
```

示例：
```
user:12345:feature:ai_write = "true"
user:12345:feature:vip_theme = "false"
```

---

#### 缓存更新策略

**写时更新**：
- 修改开关配置时，立即更新缓存
- 使用 Laravel Event 监听模型变更

```php
// 在 FeatureService 中添加缓存逻辑
public static function isEnabled(int $userId, string $featureKey): bool
{
    $cacheKey = "user:{$userId}:feature:{$featureKey}";

    // 先查缓存
    $cached = Cache::get($cacheKey);
    if ($cached !== null) {
        return $cached === 'true';
    }

    // 缓存不存在，查询数据库
    $enabled = self::checkFromDatabase($userId, $featureKey);

    // 写入缓存，有效期 1 小时
    Cache::put($cacheKey, $enabled ? 'true' : 'false', 3600);

    return $enabled;
}

// 清除缓存
public static function clearUserFeatureCache(int $userId, string $featureKey): void
{
    $cacheKey = "user:{$userId}:feature:{$featureKey}";
    Cache::forget($cacheKey);
}
```

---

#### 缓存失效场景

监听以下模型事件，自动清除缓存：

1. **UserFeatureSetting** 创建/更新/删除
2. **FeatureWhitelist** 创建/删除
3. **FeatureBlacklist** 创建/删除

```php
// 在 Model 中定义事件监听
class UserFeatureSetting extends Model
{
    protected static function booted()
    {
        static::saved(function ($model) {
            FeatureService::clearUserFeatureCache(
                $model->user_id,
                $model->feature->key
            );
        });

        static::deleted(function ($model) {
            FeatureService::clearUserFeatureCache(
                $model->user_id,
                $model->feature->key
            );
        });
    }
}
```

---

### 批量查询优化

对于获取用户所有可用功能列表的场景，避免循环查询：

```php
public static function getUserEnabledFeaturesWithCache(int $userId): Collection
{
    $allFeatures = Feature::all();

    $enabledKeys = [];
    foreach ($allFeatures as $feature) {
        if (self::isEnabled($userId, $feature->key)) {
            $enabledKeys[] = $feature->key;
        }
    }

    return $allFeatures->filter(function ($feature) use ($enabledKeys) {
        return in_array($feature->key, $enabledKeys);
    });
}
```

#### 场景1：新功能灰度发布

**需求**：上线新的 AI 写作功能，先给内部测试用户开放，验证后全量开放。

**步骤**：

```php
]);
```

2. 添加测试用户到白名单：
```php
// 添加内部测试用户（假设 user_id = 1-10）
foreach (range(1, 10) as $userId) {
    FeatureService::addToWhitelist($userId, 'ai_write', '内部测试用户');
}
```

3. 前端判断功能是否可用：
```php
// 在 Controller 中
$userId = $request->user()->id;

if ($canUseAI) {
    // 显示 AI 写作入口
}
```

4. 测试完成后，修改默认状态为开启：
```php
Feature::where('key', 'ai_write')->update(['is_enabled' => true]);

// 可选择：清空白名单，让所有用户使用
FeatureWhitelist::where('feature_id', $featureId)->delete();
```

#### 场景2：VIP 专属功能

**需求**：VIP 用户专属的深色主题功能。

**步骤**：

1. 创建功能定义：
```php
Feature::create([
    'name' => 'VIP深色主题',
    'key' => 'vip_theme',
    'description' => 'VIP专属深色主题',

]);
```

2. 用户购买 VIP 后，添加到白名单：

```php
// 在 VIP 过期检查的 Logic 中
FeatureService::removeFromWhitelist($userId, 'vip_theme');
```

#### 场景3：异常用户封禁

**需求**：发现某用户滥用功能，暂时封禁其使用。

**步骤**：

```php
FeatureService::addToBlacklist($userId, 'ai_write', '滥用功能，暂时封禁');
```

2. 黑名单生效后，用户无法使用功能（即使之前开启了）

3. 问题解决后，解除黑名单：
```php
FeatureService::removeFromBlacklist($userId, 'ai_write');
```

## 总结

功能开关系统采用**四表设计**，支持用户级别控制、白名单和黑名单机制，判断逻辑清晰，符合项目分层架构规范。

- 数据库设计清晰，四表分离职责明确
- 判断优先级：黑名单 > 白名单 > 用户设置 > 默认状态
- 代码架构符合 Models → Services → Logics → Controllers 分层规范
- 后台管理界面友好，支持快速配置
- 性能优化方案完善，支持 Redis 缓存扩展

**适用场景**：

- 新功能灰度发布
- VIP 专属功能控制
- 异常用户封禁
- 测试验证隔离

通过此方案，可以灵活管理功能开关，降低发布风险，提升用户体验。
