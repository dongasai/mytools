# 临时文件清理功能

## 功能概述

AFile 模块提供临时文件定期清理功能，自动删除超过指定天数的临时文件，释放磁盘空间。

---

## 命令说明

### 命令签名

```bash
php artisan afile:clean-temp [options]
```

### 选项参数

| 选项 | 说明 | 默认值 |
|------|------|--------|
| `--days` | 保留天数 | 3 |

---

## 使用示例

### 手动清理

```bash
# 清理 3 天前的临时文件（默认）
php artisan afile:clean-temp

# 清理 7 天前的临时文件
php artisan afile:clean-temp --days=7

# 清理所有临时文件
php artisan afile:clean-temp --days=0
```

### 执行结果

```
开始清理 3 天前的临时文件...

清理完成！
+------------+---------+
| 统计项     | 数量    |
+------------+---------+
| 删除文件数 | 10      |
| 删除目录数 | 5       |
| 释放空间   | 65.7 KB |
+------------+---------+
```

## 自动清理

### 定时任务配置

系统已配置定时任务，每天凌晨 2 点自动清理 3 天前的临时文件：

```php
// Modules/AFile/Providers/FileServiceProvider.php

$schedule->command(CleanTempFilesCommand::class, ['--days' => 3])
    ->dailyAt('02:00')
    ->name('afile-清理临时文件')
    ->withoutOverlapping()
    ->onOneServer();
```

### 启动调度器

在服务器上添加 Cron 条目：

```bash
* * * * * cd /path-to-your-project && php artisan schedule:run >> /dev/null 2>&1
```

## 清理策略

### 默认保留期

- **保留天数**：3 天
- **清理频率**：每天凌晨 2 点
- **清理范围**：`public/storage/temp/` 目录

### 清理规则

1. **按日期目录清理**：删除整个日期目录（如 `202608/14/`）
2. **保留策略**：保留最近 N 天的目录
3. **空目录清理**：自动删除空的父目录（如空的年月目录）

## 配置调整

### 修改保留天数

**方法 1：修改命令参数（推荐）**

编辑 `Modules/AFile/Providers/FileServiceProvider.php`：

```php
// 修改 --days 参数
$schedule->command(CleanTempFilesCommand::class, ['--days' => 7])  // 改为保留 7 天
    ->dailyAt('02:00');
```

**方法 2：调整定时任务频率**

```php
// 改为每周清理一次
$schedule->command(CleanTempFilesCommand::class, ['--days' => 7])
    ->weekly()  // 每周一凌晨执行
    ->at('02:00');
```

## 注意事项

1. **生产环境首次运行**：确保 `public/storage` 符号链接已创建
   ```bash
   php artisan storage:link
   ```

2. **清理时机**：建议在业务低峰期执行（如凌晨 2 点）

3. **磁盘空间监控**：定期检查临时文件目录大小
   ```bash
   du -sh public/storage/temp
   ```

4. **手动清理**：紧急情况下可手动清理整个 temp 目录
   ```bash
   rm -rf public/storage/temp/*
   ```
