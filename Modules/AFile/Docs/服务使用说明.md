# 文件模块服务使用说明

## 1. 模块概述

文件模块是一个用于处理文件和图片上传、存储和访问的基础模块。该模块提供了文件和图片的上传、存储、访问和管理功能，支持公共和私有文件的区分，以及文件与其他模块实体的关联。

## 2. 核心功能

### 2.1 文件上传与存储

- 支持普通文件和图片文件的上传
- 支持文件格式转换（如图片转WebP）
- 支持公共和私有文件的区分
- 支持文件与其他模块实体的关联

### 2.2 图片处理

- 支持图片的缩放和格式转换
- 支持图片URL的生成和访问
- 支持图片的下载和访问控制

### 2.3 临时文件处理

- 支持临时文件的创建和存储
- 支持临时文件的访问和下载
- 支持临时文件的自动清理

### 2.4 文件模板管理

- 支持文件模板的创建和管理
- 支持基于模板的文件生成

## 3. 服务使用方法

### 3.1 文件服务

文件服务提供了文件上传、下载、删除等功能。

```php
// 获取文件服务
$fileService = new \Modules\AFile\Services\FileService();

// 上传文件
$file = $fileService->uploadFile($request->file('file'), $userId);

// 上传图片
$image = $fileService->uploadImage($request->file('image'), $userId);

// 获取文件URL
$fileUrl = $fileService->getFileUrl($file->id);

// 获取图片URL
$imageUrl = $fileService->getImageUrl($image->id);

// 删除文件
$fileService->deleteFile($file->id);

// 删除图片
$fileService->deleteImage($image->id);
```

### 3.2 图片处理服务

用于处理图片文件的访问和操作。

```php
// 获取图片服务
$imgService = new \Modules\AFile\Services\ImgService();

// 通过ID获取图片URL
$imageUrl = $imgService->getPicUrl4Id($imageId);

// 通过 FileImg 模型获取图片URL
$imageUrl = $imgService->getPicUrl($fileImg);

// 获取私有图片URL（仅当有权限时）
$privateImageUrl = $imgService->getPicUrl($fileImg, true);

// 通过路径获取管理后台图片URL
$adminImageUrl = $imgService->getAdminPicUrl($imagePath);

// 下载图片
$response = $imgService->download($fileImg);

// 将图片数组转换为URL数组
$imageUrls = $imgService->imgArr2imgArrurl($imageArray);
```

### 3.3 文件操作服务

用于处理普通文件的访问和操作。

```php
// 获取文件基础逻辑
$fileBaseLogic = new \Modules\AFile\Logics\FileBaseLogic();

// 获取文件内容
$content = $fileBaseLogic->getPath($filePath, $disk);

// 获取文件的完整物理路径
$fullPath = $fileBaseLogic->prefixPath($filePath);

// 检查文件是否存在
$exists = $fileBaseLogic->fileExists($filePath);

// 获取文件可见性
$visibility = $fileBaseLogic->getVisibility($filePath);
```

### 3.4 临时文件服务

用于处理临时文件的创建、存储和访问。

```php
// 获取临时文件服务
$temporaryService = new \Modules\AFile\Services\TemporaryService();

// 保存临时文件，返回存储路径
$path = $temporaryService->save('jpg', $fileContent);

// 获取临时文件的下载URL
$downloadUrl = $temporaryService->getDownUrl($path);

// 获取临时文件的下载响应
$response = $temporaryService->getDown($path);

// 获取本地临时文件路径
$localPath = $temporaryService->getTempLocalFile();
```

## 4. 与其他模块的交互

### 4.2 与内容模块的交互

### 4.3 与商品模块的交互

- 商品详情中多图片的处理

## 5. 配置说明

文件模块使用Laravel的文件系统配置，主要配置项包括：

- `FILESYSTEM_DISK`: 默认存储磁盘兜底配置（数据库无默认盘配置时使用），默认为'local'
- 磁盘配置主要由数据库 `file_storage_configs` 表管理：
  - `is_default=true` 的记录作为默认存储磁盘
  - `is_temp=true` 的记录作为临时文件存储磁盘
  - 临时盘未配置时回退默认盘

这些配置可以在.env文件中设置（仅作为数据库未配置时的兜底）。

## 6. 验证器使用

### 6.1 用户图片文件验证器

用于验证图片文件是否属于指定用户。

```php
// 验证图片是否属于用户
$validator = new \Modules\AFile\Validator\UserFileImgValidator();
$isValid = $validator->validate($fileImgId, ['user_id' => $userId]);
```

## 7. 最佳实践

### 7.1 文件上传

- 使用 `UploadService` 类处理用户上传的文件
- 对上传的文件进行类型和大小的验证
- 使用唯一的文件名避免文件名冲突

### 7.2 图片处理

- 使用WebP格式存储图片以节省空间
- 根据需要生成不同尺寸的图片
- 使用CDN加速图片访问

### 7.3 文件安全

- 对私有文件进行访问控制
- 定期清理临时文件
- 使用软删除避免误删文件
