# 文件模块数据库设计

## 1. 数据库表概览

文件模块包含以下核心数据表：

1. **file_files** - 普通文件表
2. **file_imgs** - 图片文件表
3. **file_template** - 文件模板表

## 2. 表结构详细设计

### 2.1 普通文件表 (file_files)

存储普通文件的基本信息。

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
|-------|------|-------|-------|------|
| id | bigint | 否 | 自增 | 主键 |
| path | varchar(1000) | 是 | NULL | 存储目录 |
| re_type | varchar(100) | 是 | '0' | 关联类型 |
| re_id | int | 否 | - | 关联ID |
| o_name | varchar(200) | 否 | - | 原文件名 |
| fsize | bigint | 是 | 0 | 文件大小(字节) |
| type1 | varchar(100) | 是 | NULL | 文件类型 |
| updated_at | timestamp | 是 | NULL | 更新时间 |
| created_at | timestamp | 是 | NULL | 创建时间 |
| deleted_at | timestamp | 是 | NULL | 删除时间(软删除) |

### 2.2 图片文件表 (file_imgs)

存储图片文件的基本信息和额外的图片相关属性。

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
|-------|------|-------|-------|------|
| id | bigint | 否 | 自增 | 主键 |
| storage_disk | varchar(100) | 是 | NULL | 存储磁盘 |
| path | varchar(1000) | 是 | NULL | 存储路径 |
| user_id | bigint unsigned | 是 | 0 | 用户ID |
| admin_id | bigint unsigned | 是 | 0 | 管理员ID |
| re_type | varchar(100) | 是 | '0' | 关联类型 |
| re_id | int | 否 | - | 关联ID |
| o_name | varchar(200) | 否 | - | 原文件名 |
| fsize | bigint | 是 | 0 | 文件大小(字节) |
| width | int | 是 | 0 | 图片宽度(像素) |
| height | varchar(1000) | 是 | NULL | 图片高度(像素) |
| type1 | varchar(100) | 是 | NULL | 图片类型 |
| private | tinyint unsigned | 是 | 0 | 是否私有，0:公共，1:私有 |
| updated_at | timestamp | 是 | NULL | 更新时间 |
| created_at | timestamp | 是 | NULL | 创建时间 |
| deleted_at | timestamp | 是 | NULL | 删除时间(软删除) |

### 2.3 文件模板表 (file_template)

存储文件模板信息，用于基于模板生成文件。

| 字段名 | 类型 | 允许空 | 默认值 | 说明 |
|-------|------|-------|-------|------|
| id | bigint | 否 | 自增 | 主键 |
| unid | varchar(500) | 是 | NULL | 唯一标识 |
| file_id | int | 是 | NULL | 关联的文件ID |
| title | varchar(500) | 否 | - | 模板标题 |
| desc | varchar(100) | 是 | NULL | 模板描述 |
| status | varchar(1) | 是 | NULL | 状态，0:无效，1:有效 |
| group | varchar(100) | 是 | NULL | 模板分组 |
| updated_at | timestamp | 是 | NULL | 更新时间 |
| created_at | timestamp | 是 | NULL | 创建时间 |
| deleted_at | timestamp | 是 | NULL | 删除时间(软删除) |

## 3. 表关系

### 3.1 FileTemplate 与 FileImg 的关系

FileTemplate 表通过 file_id 字段与 FileImg 表的 id 字段建立一对一关系，表示模板关联的图片文件。

```php
// 在 FileTemplate 模型中定义关系
public function file()
{
    return $this->hasOne(FileImg::class, 'id', 'file_id');
}
```

### 3.2 文件与其他模块实体的关系

文件表和图片表通过 re_type 和 re_id 字段与其他模块的实体建立多态关联关系。re_type 表示关联的实体类型，re_id 表示关联的实体ID。

## 4. 索引设计

### 4.1 file_files 表索引

- 主键索引：id

### 4.2 file_imgs 表索引

- 主键索引：id
- 建议添加索引：(user_id)、(re_type, re_id)

### 4.3 file_template 表索引

- 主键索引：id
- 建议添加索引：(unid)、(file_id)

## 5. 数据库表前缀

所有数据库表都使用 `` 前缀，例如：
- `file_files`
- `file_imgs`
- `file_template`
