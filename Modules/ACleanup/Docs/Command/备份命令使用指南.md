## 一、发起备份

### RunBackupCommand

**命令**: `php artisan backup:run {plan_id}`

**功能**: 发起备份任务，输出批次ID

**示例**：
```bash
$ php artisan backup:run 1

✓ 备份批次已创建
  批次ID: 123
  计划名称: 生产数据备份
  目标表数: 50

监控进度：
  php artisan backup:progress 123
```

**输出内容**：
- ✅ 批次ID（用于监控）
- ✅ 计划名称
- ✅ 目标表数
- ✅ 监控命令提示

## 四、参数说明

### RunBackupCommand

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `plan_id` | 参数 | ✅ 是 | 备份计划ID |

**示例**：
```bash
php artisan backup:run 1      # 发起计划 #1 的备份
php artisan backup:run 5      # 发起计划 #5 的备份
```

### BackupProgressCommand

| 参数 | 类型 | 必需 | 默认行为 | 说明 |
|------|------|------|---------|------|
| `batch_id` | 参数 | ❌ 否 | 查找最新备份 | 备份批次ID |
| `--once` | 选项 | ❌ 否 | 持续监控 | 仅查看一次不监控 |
| `--interval` | 选项 | ❌ 否 | 2秒 | 监控刷新间隔（秒） |

**示例**：
```bash
php artisan backup:progress              # 监控最新备份
php artisan backup:progress 123          # 监控批次 #123
php artisan backup:progress 123 --once   # 查看一次批次 #123
php artisan backup:progress --interval=5 # 监控最新备份（5秒刷新）
```

## 六、常见问题

### Q1: 如何找到备份计划ID？

**方法1**: 查看数据库
```sql
SELECT id, plan_name FROM cleanup_backup_plans WHERE is_enabled = 1;
```

**方法2**: 后台管理界面
- 访问：`/admin/backup-clean-admin/backup-plans`
- 查看计划列表中的ID

### Q2: 如何查看所有批次？

**方法1**: 数据库查询
```sql
SELECT id, batch_name, batch_status, created_at
FROM cleanup_backup_run_batches
ORDER BY created_at DESC;
```

**方法2**: 后台管理界面
- 访问：`/admin/backup-clean-admin/batches`

### Q3: 监控时如何退出？

**方法**: 按 `Ctrl+C` 退出监控
- 监控不会影响备份任务
- 备份任务继续在后台执行
- 可随时重新监控

### Q4: 备份失败怎么办？

**查看错误**:
```bash
$ php artisan backup:progress {batch_id}

状态: ❌ 失败
错误: [错误信息]
```

**重试批次**:
- 后台管理界面：批次详情页 → 重试批次按钮

### Q5: 如何查看备份文件？

**文件位置**: `storage/app/backup/{日期}/batch_{批次ID}/`

**示例**:
```
storage/app/backup/2026-08-23/batch_123/
  ├── users.sql
  ├── orders.sql
  └── products.sql
```
