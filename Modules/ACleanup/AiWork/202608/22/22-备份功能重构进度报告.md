## 二、架构设计

### 2.1 执行流程

```
RunBackupCommand
  └─> 创建批次记录 (CleanupBackupRunBatch)
  └─> 派发 ProcessBackupBatchJob
       └─> 分析表，创建表备份记录 (CleanupBackupRunTable)
       └─> 为每个表派发 ProcessTableBackupJob
            ├─> 小表：直接备份
            └─> 大表：拆分多个 ProcessTableSplitJob
                 └─> 每个分批备份一部分数据
```

### 2.2 进度跟踪

- **批次进度**：`cleanup_backup_run_batches` 表
  - total_tables：总表数
  - processed_tables：已处理表数
  - progress_percent：进度百分比

- **表进度**：`cleanup_backup_run_tables` 表
  - total_records：总记录数
  - processed_records：已处理记录数
  - progress_percent：进度百分比

- **分批进度**：`cleanup_backup_run_table_splits` 表
  - offset：起始偏移量
  - limit：每批数量
  - records_count：实际记录数

**现象**：
- 命令成功创建批次记录
- 命令成功派发 ProcessBackupBatchJob
- 但队列worker没有执行任务

**表现**：
```

进度: 0.00%
表数: 0/0 | 失败: 0
```

**数据库验证**：
```sql
SELECT * FROM jobs;  -- 空的，队列中无任务
SELECT * FROM cleanup_backup_run_batches;  -- batch_status = 0 (等待中)
```

### 3.2 可能原因

1. **队列配置问题**：队列连接配置不正确
2. **任务派发失败**：dispatch() 调用失败但未报错
3. **队列worker问题**：worker启动后立即退出
4. **代码缓存问题**：队列worker使用旧代码
