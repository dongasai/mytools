# 配置表备份枚举类型说明

> 使用枚举类型增强配置的类型安全性和代码可维护性

## 🎯 概述

配置表备份系统使用PHP 8+的枚举类型来约束配置值，提供类型安全和更好的开发体验。

## 📋 可用枚举类型

### 1. ConfigDbType - 配置类型枚举

定义了配置表的选择方式：

```php
enum ConfigDbType: string
{
    case MODEL = 'model';      // 模型类型
    case PREFIX = 'prefix';    // 前缀类型
}
```

**使用示例：**
```php
'tables' => [
    'example_model' => [
        'type' => ConfigDbType::MODEL->value,
        'model' => \Module\Example\Models\ExampleConfig::class,
        // ...
    ],

    'example_prefix' => [
        'type' => ConfigDbType::PREFIX->value,
        'prefix' => 'example_',
        // ...
    ],
],
```

**可用方法：**
- `getDescription()` - 获取类型描述
- `getIcon()` - 获取类型图标
- `isValid(string $type)` - 验证类型是否有效
- `getAllTypes()` - 获取所有可用类型

### 2. ConfigDbBackupMode - 备份模式枚举

定义了备份的内容范围：

```php
enum ConfigDbBackupMode: string
{
    case FULL = 'full';              // 完整备份
    case STRUCTURE_ONLY = 'structure_only';  // 仅结构
    case DATA_ONLY = 'data_only';      // 仅数据
}
```

**使用示例：**
```php
'global_settings' => [
    'backup_mode' => ConfigDbBackupMode::FULL->value,
    // ...
],

'tables' => [
    'template_table' => [
        'backup_mode' => ConfigDbBackupMode::STRUCTURE_ONLY->value,
        // ...
    ],
],
```

**可用方法：**
- `getDescription()` - 获取模式描述
- `getIcon()` - 获取模式图标
- `includesStructure()` - 是否包含表结构
- `includesData()` - 是否包含数据
- `getFileSuffix()` - 获取文件后缀

### 3. ConfigDbCompressionType - 压缩类型枚举

定义了备份文件的压缩方式：

```php
enum ConfigDbCompressionType: string
{
    case NONE = 'none';    // 不压缩
    case GZIP = 'gzip';    // GZIP压缩
    case BZIP2 = 'bzip2';  // BZIP2压缩
    case ZIP = 'zip';      // ZIP压缩
}
```

**使用示例：**
```php
'global_settings' => [
    'compression' => [
        'type' => ConfigDbCompressionType::GZIP->value,
        'level' => ConfigDbCompressionType::GZIP->getDefaultCompressionLevel(),
    ],
],
```

**可用方法：**
- `getDescription()` - 获取压缩类型描述
- `getFileExtension()` - 获取文件扩展名
- `getCompressionRange()` - 获取压缩级别范围
- `getDefaultCompressionLevel()` - 获取默认压缩级别
- `supportsCompression()` - 是否支持压缩

### 4. ConfigDbNotificationChannel - 通知渠道枚举

定义了备份通知的发送渠道：

```php
enum ConfigDbNotificationChannel: string
{
    case LOG = 'log';          // 日志记录
    case EMAIL = 'email';      // 邮件通知
    case SLACK = 'slack';      // Slack通知
    case WEBHOOK = 'webhook';  // Webhook通知
    case DATABASE = 'database'; // 数据库记录
}
```

**使用示例：**
```php
'notifications' => [
    'on_success' => false,
    'on_failure' => true,
    'channels' => [
        ConfigDbNotificationChannel::LOG->value,
        ConfigDbNotificationChannel::EMAIL->value,
    ],
],
```

**可用方法：**
- `getDescription()` - 获取渠道描述
- `getIcon()` - 获取渠道图标
- `isAsync()` - 是否异步处理
- `getRequiredConfig()` - 获取配置要求
- `getExampleConfig()` - 获取示例配置

### 5. ConfigDbValidationRule - 验证规则枚举

定义了配置验证的规则类型：

```php
enum ConfigDbValidationRule: string
{
    case REQUIRED = 'required';
    case STRING = 'string';
    case INTEGER = 'integer';
    case BOOLEAN = 'boolean';
    case ARRAY = 'array';
    case EMAIL = 'email';
    case URL = 'url';
    case DATE = 'date';
    // ... 更多规则
}
```

**使用示例：**
```php
'validation_rules' => [
    'module_name' => [
        ConfigDbValidationRule::REQUIRED->value,
        ConfigDbValidationRule::STRING->value,
    ],
],
```

## 🔧 工具类使用

### ConfigDbEnumHelper 辅助工具

提供了便捷的枚举操作方法：

```php
use Modules\ABase\Support\ConfigDbEnumHelper;

// 获取所有配置类型
$types = ConfigDbEnumHelper::getConfigTypes();

// 验证配置类型
$isValid = ConfigDbEnumHelper::validateConfigType('model');

// 格式化为选择数组
$selectOptions = ConfigDbEnumHelper::formatEnumForSelect('config_type');

// 验证整个配置
$validation = ConfigDbEnumHelper::validateConfigEnums($config);

// 获取枚举统计
$stats = ConfigDbEnumHelper::getEnumStatistics();
```

## ✨ 配置验证

系统会自动验证配置文件中的枚举值：

```php
// ✅ 正确的配置
'type' => ConfigDbType::MODEL->value,

// ❌ 错误的配置（会在运行时报错）
'type' => 'invalid_type',
```

**错误信息示例：**
```
InvalidArgumentException: 表 example_table 的类型 'invalid_type' 无效。
有效类型: model, prefix
```

## 📚 最佳实践

### 1. 使用枚举值而不是字符串

```php
// ✅ 推荐
'type' => ConfigDbType::MODEL->value,

// ❌ 不推荐
'type' => 'model',
```

### 2. 利用枚举方法获取信息

```php
// ✅ 推荐
$description = ConfigDbType::MODEL->getDescription();
$icon = ConfigDbType::MODEL->getIcon();

// ❌ 不推荐
$description = '模型类型 - 通过模型类精确指定表';
$icon = '📄';
```

### 3. 使用工具类进行验证

```php
// ✅ 推荐
if (!ConfigDbEnumHelper::validateConfigType($type)) {
    throw new InvalidArgumentException('Invalid config type');
}

// ✅ 也可以
if (!ConfigDbType::isValid($type)) {
    throw new InvalidArgumentException('Invalid config type');
}
```

### 4. 配置文件中使用枚举

```php
use Modules\ABase\Enums\ConfigDbType;
use Modules\ABase\Enums\ConfigDbBackupMode;

return [
    'tables' => [
        'example' => [
            'type' => ConfigDbType::MODEL->value,
            'backup_mode' => ConfigDbBackupMode::FULL->value,
        ],
    ],
];
```

## 🚀 扩展枚举

如需添加新的枚举值：

1. 修改对应的枚举类
2. 添加新的case
3. 实现相应的方法
4. 更新工具类（如需要）

**示例：添加新的配置类型**
```php
enum ConfigDbType: string
{
    case MODEL = 'model';
    case PREFIX = 'prefix';
    case QUERY = 'query';  // 新增：SQL查询类型

    public function getDescription(): string
    {
        return match($this) {
            self::MODEL => '模型类型 - 通过模型类精确指定表',
            self::PREFIX => '前缀类型 - 通过表前缀批量指定表',
            self::QUERY => '查询类型 - 通过SQL查询自定义表',  // 新增
        };
    }
}
```

## 🔍 调试和故障排除

### 1. 查看可用枚举值

```bash
php artisan tinker
>>> use Modules\ABase\Support\ConfigDbEnumHelper;
>>> ConfigDbEnumHelper::getConfigTypes();
```

### 2. 验证配置文件

```bash
php artisan abase:generate:configdb --list
# 如果配置有误，会显示具体的错误信息
```

### 3. 检查枚举验证

```php
use Modules\ABase\Support\ConfigDbEnumHelper;

$config = include 'config/configdb.php';
$validation = ConfigDbEnumHelper::validateConfigEnums($config);

if (!$validation['valid']) {
    foreach ($validation['errors'] as $error) {
        echo "错误: $error\n";
    }
}
```
