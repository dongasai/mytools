# 项目主模块创建引导

本文档指导如何为项目创建一个主模块，用于承载项目核心功能和全局入口。

## 重要说明

**执行方式**：本文档描述的创建过程必须使用以下方式执行：

- **Agent**: `task-dev` - 使用 task-dev agent 来完成项目主模块的开发工作
- **激活技能**: 必须激活以下技能
  - `dev-dcatadmin` - Dcat Admin 开发技能（Grid/Form/Action/Metric 开发）
  - `admin-menu` - 后台菜单配置技能（菜单创建和同步）

**示例命令**：
```
请使用 task-dev agent，激活 dev-dcatadmin 和 admin-menu 技能，按照 docs/起新项目-项目主模块.md 文档创建项目主模块
```

## 一、为什么需要项目主模块

### 问题背景

在模块化项目中，经常遇到以下问题：

1. **后台首页无处放置** - 主应用的 `app/Admin/routes.php` 不能修改
2. **全局功能缺乏归属** - 系统级功能（首页、仪表盘、全局配置）没有专门的模块
3. **项目特性不明显** - 缺少能体现项目定位的核心模块

### 解决方案

创建一个**项目主模块**，承担以下职责：

- 后台首页
- 系统仪表盘
- 全局配置管理
- 项目级核心功能

### 命名建议

推荐使用项目相关的命名：

| 项目类型 | 推荐模块名 | 示例 |
|---------|-----------|------|
| 三牛项目 | NnnnMain | 三牛主模块 |
| 企业系统 | EnterpriseMain | 企业主模块 |
| 自定义项目 | {Project}Main | 项目主模块 |

## 二、创建步骤

### 第一步：创建模块目录结构

手动创建模块目录，不使用 `php artisan module:make`：

```bash
# 创建模块主目录
mkdir -p Modules/NnnnMain

# 创建后台目录
mkdir -p Modules/NnnnMain/DcatAdmin/Controllers

# 创建配置目录
mkdir -p Modules/NnnnMain/config

# 创建路由目录
mkdir -p Modules/NnnnMain/routes

# 创建 Providers 目录
mkdir -p Modules/NnnnMain/app/Providers
```

**创建后的目录结构**：
```
Modules/NnnnMain/
├── app/
│   └── Providers/
│       ├── NnnnMainServiceProvider.php
│       └── RouteServiceProvider.php
├── DcatAdmin/
│   └── Controllers/
├── config/
└── routes/
```

### 第二步：创建后台首页控制器

**创建文件**：`Modules/NnnnMain/DcatAdmin/Controllers/HomeController.php`

**方案A：复制现有首页**（推荐）

如果项目已有后台首页实现（如 Application 模块），直接复制：

```php
<?php

namespace Modules\NnnnMain\DcatAdmin\Controllers;

use Dcat\Admin\Layout\Content;
use Dcat\Admin\Layout\Row;
use Dcat\Admin\Widgets\Card;
use Illuminate\Routing\Controller;
use Modules\AFile\DcatAdmin\Metrics\FileStorageConfigCheckMetric;
use Modules\Application\DcatAdmin\Metrics\CacheClearMetric;
use Modules\Application\DcatAdmin\Metrics\DatabaseHealth;
use Modules\Application\DcatAdmin\Metrics\PhpDisabledFunctionsMetric;
use Modules\Application\DcatAdmin\Metrics\SystemLogErrors;
use Modules\ABase\DcatAdmin\Metrics\RequestLogConfigCheckMetric;

/**
 * 后台首页控制器
 */
class HomeController extends Controller
{
    protected $title = '项目名称';

    public function index(Content $content)
    {
        return $content
            ->title($this->title)
            ->description('项目定位描述')
            ->body(function (Row $row) {
                // 系统状态监控卡片
                $row->column(3, new Card(new FileStorageConfigCheckMetric()));
                $row->column(3, new Card(new CacheClearMetric()));
                $row->column(3, new Card(new DatabaseHealth()));
                $row->column(3, new Card(new RequestLogConfigCheckMetric()));
            })
            ->body(function (Row $row) {
                // PHP环境检查
                $row->column(4, new Card(new PhpDisabledFunctionsMetric()));
            })
            ->body(function (Row $row) {
                // 系统日志监控
                $row->column(4, new Card(new SystemLogErrors()));
            });
    }
}
```

**方案B：创建简单首页**

如果项目是新项目，创建简单首页：

```php
<?php

namespace Modules\NnnnMain\DcatAdmin\Controllers;

use Dcat\Admin\Http\Controllers\Dashboard;
use Dcat\Admin\Layout\Column;
use Dcat\Admin\Layout\Content;
use Dcat\Admin\Layout\Row;
use Illuminate\Routing\Controller;

class HomeController extends Controller
{
    public function index(Content $content)
    {
        return $content
            ->header('项目名称')
            ->description('项目定位')
            ->body(function (Row $row) {
                $row->column(12, function (Column $column) {
                    $column->row(Dashboard::title());
                });

                // TODO: 后续添加项目专属的仪表盘组件
            });
    }
}
```

### 第三步：创建后台路由

**创建文件**：`Modules/NnnnMain/routes/admin.php`

```php
<?php

use Illuminate\Support\Facades\Route;
use Modules\NnnnMain\DcatAdmin\Controllers\HomeController;

/*
|--------------------------------------------------------------------------
| 项目主模块 - 后台路由
|--------------------------------------------------------------------------
*/

// 后台首页
Route::get('/', [HomeController::class, 'index'])->name('nnnn_main.home');
```

**注意**：
- ✅ 路由文件放在 `routes/admin.php`
- ❌ 不要放在 `DcatAdmin/routes/admin.php`（该路径不会被自动加载）

### 第四步：创建菜单配置

**创建文件**：`Modules/NnnnMain/config/admin_menu.php`

```php

return [

        'title' => '首页',
        'uri' => '/',
        'icon' => 'feather icon-home',
        'show' => true,
        'children' => [],

```

### 第五步：创建 ServiceProvider 文件

**创建文件**：`Modules/NnnnMain/app/Providers/RouteServiceProvider.php`

```php
<?php

namespace Modules\NnnnMain\Providers;

use Illuminate\Foundation\Support\Providers\RouteServiceProvider as ServiceProvider;
use Modules\DcatAdmin\Support\Traits\RouteServiceProviderTrait;

class RouteServiceProvider extends ServiceProvider
{
    use RouteServiceProviderTrait;

    protected string $name = 'NnnnMain';

    protected string $nameLower = 'nnnn_main';

    public function boot(): void
    {
        parent::boot();
    }

    public function map(): void
    {
        // Admin后台路由
        $this->mapAdminRoutes();

        // API路由
        $this->mapApiRoutes();

        // Web路由
        $this->mapWebRoutes();
    }
}
```

**关键点**：
- ✅ 使用 `RouteServiceProviderTrait` trait
- ✅ 在 `map()` 中调用 `$this->mapAdminRoutes()`
- ✅ 该 trait 会自动加载 `routes/admin.php`

### 第六步：创建主服务提供者

**创建文件**：`Modules/NnnnMain/app/Providers/NnnnMainServiceProvider.php`

```php
<?php

namespace Modules\NnnnMain\Providers;

use Modules\ABase\Support\ServiceProvider;

class NnnnMainServiceProvider extends ServiceProvider
{
    protected string $name = 'NnnnMain';

    protected string $nameLower = 'nnnn_main';

    public function boot(): void
    {
        $this->modulePath = dirname(__DIR__, 2);
        parent::boot();
    }

    public function register(): void
    {
        $this->app->register(RouteServiceProvider::class);
    }
}
```

### 第七步：创建模块信息文件

**创建文件**：`Modules/NnnnMain/module.json`

```json
{
    "name": "NnnnMain",
    "alias": "项目主模块",
    "description": "项目主模块，承载项目核心功能：后台首页、系统仪表盘、全局配置等",
    "keywords": ["主模块", "首页", "仪表盘"],
    "priority": 50,
    "providers": [
        "Modules\\NnnnMain\\Providers\\NnnnMainServiceProvider"
    ],
    "files": []
}
```

**优先级建议**：
- 项目主模块：`priority: 50`
- 核心业务模块：`priority: 30-40`
- 工具模块：`priority: 0-20`

### 第八步：启用模块

**编辑文件**：`modules_statuses.json`

```json
{
    "NnnnMain": true,
    "ABase": true,
    // ... 其他模块
}
```

将 `NnnnMain` 放在列表第一位，便于识别。

## 四、常见问题

### Q1: 首页路由不生效

**原因**：路由文件位置错误

**解决**：
```bash
# 确认路由文件位置
ls Modules/NnnnMain/routes/admin.php

# 如果在 DcatAdmin/routes/admin.php，需要移动
mv Modules/NnnnMain/DcatAdmin/routes/admin.php Modules/NnnnMain/routes/admin.php
```

### Q2: ServiceProvider 找不到 ABase\Support\ServiceProvider

**原因**：命名空间错误

**解决**：
```php
// 错误
use ABase\Support\ServiceProvider;

// 正确
use Modules\ABase\Support\ServiceProvider;
```

### Q3: 首页空白或报错

**原因**：HomeController 依赖的 Metric 类不存在

**解决**：
1. 检查 HomeController 中引用的 Metric 是否存在
2. 如果不存在，先移除相关代码，或创建对应的 Metric

### Q4: 菜单同步错误

**原因**：菜单配置格式错误

**解决**：
```php
// 检查 admin_menu.php 格式
return [
    [
        'title' => '首页',    // 必需
        'uri' => '/',         // 必需
        'icon' => 'feather icon-home',  // 推荐
        'show' => true,       // 可选
        'children' => [],     // 可选
    ],
];
```

## 五、最佳实践

### 模块职责划分

**项目主模块（NnnnMain）**：
- ✅ 后台首页
- ✅ 系统全局状态
- ✅ 项目级配置入口

**Application 模块**：
- ✅ 应用配置管理
- ✅ 系统工具
- ✅ 开发者工具

**业务模块**：
- ✅ 具体业务功能
- ❌ 不要放全局功能

### 首页内容建议

**系统监控**：
- 配置检查（文件存储、缓存、数据库）
- PHP环境检查
- 系统日志监控
- 性能指标

**项目特性**：
- AI 统计（AI项目）
- 业务统计（业务系统）
- 用户活跃度
- 数据分析图表

### 性能优化

**首页加载优化**：
- Metric 查询要高效（避免复杂SQL）
- 使用缓存（配置检查结果缓存）
- 异步加载（耗时数据异步获取）

**示例**：
```php
// Metric 中使用缓存
public function render()
{
    $data = Cache::remember('home_metric', 60, function () {
        // 耗时查询
    });

    // 渲染
}
```
