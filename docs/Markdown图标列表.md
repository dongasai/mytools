## 使用建议

1. **保持一致性**: 在同一文档中使用相同的图标表示相同的含义
2. **适度使用**: 不要过度使用图标，影响阅读体验
3. **语义清晰**: 选择含义明确的图标，避免歧义
4. **可访问性**: 考虑图标在所有设备上的显示效果
5. **组合使用**: 可以将图标与文字组合，增强表达效果
