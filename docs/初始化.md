# 初始化项目(这不是起新项目的流程)

## 权限

sudo chown -R dongasai:www {项目目录}
sudo chmod -R g+rw {项目目录}



## 数据库

<!--先清空-->
php artisan db:wipe --force

php artisan migrate

php artisan module:migrate 
php artisan module:migrate  --all

php artisan module:seed 
php artisan module:seed User
php artisan module:seed NtMain

php artisan module:seed --all


- 缺少Dcat的登陆用户信息
```bash
php artisan admin:install

# 登录信息 admin admin
```
php artisan admin:sync-menu
